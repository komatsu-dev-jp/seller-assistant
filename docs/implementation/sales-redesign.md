本人の選択は「軸C、ホームC、商品B、発送C、レポートC」。その後「実装して下さい」と依頼。今回の依頼は実装までで、公開・PR・mergeは行わない。5つの入口を刷新し、箱の検品・比較事例・ブランド選択などの既存入力処理は保持する。

- ナビゲーションはホーム／商品／発送／レポート／設定。在庫は商品の中で管理。

- 未売却は見込み、売却日は売上集計、経費は記録日で集計。利益と入金を区別。
