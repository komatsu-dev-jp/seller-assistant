# PC画面26 ローカル画像プレビュー実装契約

## 結論

PC画面26の「画像を選ぶ」は、本人が選んだ販売状況の画像を同じブラウザー内で見比べるところまで実動作にする。画像はサーバーや外部サービスへ送らず、OCR（画像内の文字を自動で読む処理）や数値の自動入力も行わない。

## 今回実装すること

- JPEG、PNG、WebPを1枚選べる。
- 選んだ画像はブラウザーの一時URLで表示し、商品ごとに分けて保持する。
- 別商品へ移動して戻った場合は、その商品の画像だけを再表示する。
- 有効な画像を表示できた後だけ、入力元を「本人が画像と比較して確認」にする。
- 差し替えた古い画像と画面終了時の画像は一時URLを解放する。
- 未対応形式、空ファイル、10MB超、縦横10,000px超、4,000万画素超、表示失敗は日本語で説明する。

## 今回実装しないこと

- OCR、画像からの数値候補、自動入力。
- 画像または販売状況のAPI送信、サーバー保存、外部送信。
- メルカリ画面の自動取得、自動値下げ、自動更新。
- 実iPhoneの写真選択確認。

## 合格条件

- 「画像を選ぶ」で有効な画像が同じ画面に表示される。
- 選んだ画像が別商品へ混ざらない。
- 画像を表示しても数値は自動変更されない。
- 画像を選ばない・選択を取り消す場合に既存入力を壊さない。
- 1536×1024と768×1024で、操作部品の重なりと画面外はみ出しがない。
- console error/warningが0件で、対象テスト、Web型、整形、全体`npm run check`に合格する。
- 実装者とは別のAstra担当がコード、テスト、ブラウザー証拠を確認する。

## 安全境界

ローカル画像は`blob:`形式の一時URLとしてブラウザー内だけで扱う。`fetch`、API、データベース、外部サービスへ渡さない。画面には「PC内だけの一時プレビュー・保存されません」と表示し、保存済みや自動読取済みと誤認させない。
