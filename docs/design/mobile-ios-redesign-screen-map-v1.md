## 共通フッター

- `ホーム`: 今日やること、続き、通知。
- `作業`: 自分に割り当てられた検品、撮影、採寸、発送。
- `商品`: 仕入れ、商品情報、写真、文章、公式画面への受け渡し。
- `在庫`: 格納、移動、棚卸し、返品。
- `会計`: 売上の事実、会計設定、会計ソフト用ファイル。

メンバー、権限、ヘルプ、アプリ設定は、上部のアカウントメニューから開く。

フッターは上位画面への移動だけに使う。撮影、保存、追加は各画面の主ボタンにする。全画面で同じ並びを保ち、権限がない領域は説明付きの利用不可状態または担当範囲の入口を表示する。

## 主要導線

`ホーム → レシート撮影 → 読み取り確認 → 在庫番号 → 場所写真 → 商品を読む → 棚を読む → 格納 → 検品 → 汚れ・傷 → 写真一覧 → 1枚ずつ撮影 → 1か所ずつ採寸 → タグ確認 → 商品まとめ → 文章候補 → 公式画面へ本人が移る → 注文 → 取り出し → 梱包 → 発送 → 棚卸し → 返品確認 → 売上の事実 → 会計の基本設定 → 会計項目 → 作成前確認 → ファイル確認 → 手動取込結果 → 履歴`

## モックの作り方

- Slack選定前: A/B/Cそれぞれ、同じ5つの代表画面（ホーム、検品、撮影、採寸、商品まとめ）をラフ品質で比較する。
- Slack選定後: 採用案だけで上記49ページを高精度化し、8〜10枚のボードへ分ける。
- 高精度モックでは、通常、空、入力途中、送信待ち、要確認、エラー、完了の主要状態も必要な画面へ追加する。
- 画像の細かな文字を仕様の正本にせず、本書と採用後の正確な文言表を実装基準にする。
