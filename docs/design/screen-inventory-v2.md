## 主要導線

### 商品化

`追加 → 仕入紐付け → 撮影 → 非生成の標準加工 → 原本比較・人の承認 → カテゴリ別採寸 → 属性確認 → AI文章 → 担当者提出 → 責任者承認 → チャネル検証 → 下書き引き渡し`

### 画像加工

MVP:

`原本保管 → 加工用ZIP書出し → 利用者がPhotoroom ProでBatch加工 → 加工済ZIP再取込 → SKU照合 → 原本/加工後比較 → 人が承認`

正式連携候補:

`Photoroomへ顧客向け組込み用途を説明 → 書面許諾・契約 → サーバーでAPIキー保管 → 公式APIで非生成標準加工 → 原本比較 → 人が承認`

Codex/RPAによるPhotoroom Web画面の自動ログイン・クリック・大量処理は製品機能にしない。Photoroom Pro契約とAPI契約は別として表示する。

### カテゴリ別採寸

`カテゴリ・形状選択 → 定義バージョン固定 → 1項目ずつ測定線を表示 → 人が値・単位・測定状態を入力 → 証拠写真 → 異常候補・再測定 → 人が確定 → 監査ログ`

トップス、アウター、パンツ、スカート、ワンピース、ニット、靴、バッグ、帽子のテンプレートとカスタム項目を用意する。平置幅と一周を別値にする。

### 在庫ロケーション

`受入 → 在庫管理番号発行 → 部屋/棚/段/箱を場所ツリーから選択 → 商品ラベル読取 → 場所ラベル読取 → 写真で位置確認 → 人が格納確定 → 移動履歴 → 注文引当 → 同じ二重読取でピッキング → 棚卸 → 差異の再確認と承認`

SKUは商品情報、InventoryUnitは現物1点として分ける。棚卸の未発見・誤棚・予定外発見を自動で現在地へ反映せず、別担当の再確認と在庫責任者の承認を残す。

### 個人メルカリ

`出品パック確認 → 文章コピー・写真書き出し → 公式画面で本人が下書き保存 → アプリへ保存済み記録 → 公開後URL登録`

### メルカリShops

無料MVPの公式経路:

`商品検証 → 非公開CSV＋画像フォルダを書き出す → 公式管理画面で本人または公式スタッフがアップロード → 非公開商品を確認 → 公開 → 商品ID・確認済みURLを記録`

契約後の公式API経路:

`契約・書面承認・API_CLIENT_NAME確認 → 公式APIでUNOPENED作成 → 商品ID保存 → 責任者承認 → OPENED公開 → 公式画面で確認済みURLを記録 → 同期監査`

`UNOPENED` は入力途中の下書きではなく、必須項目が揃った非公開商品として表示する。商品IDからURLを推測しない。

### 販売から帳簿

`注文取込 → 在庫引当 → ピッキング → 梱包 → 発送 → 売上・手数料・送料作成 → 入金照合 → 仕訳候補 → 人が承認 → 会計CSV`

### 月次・仕入先分析

`取引完了・返金・原価・手数料・送料を集計 → 月間運用収支 → 仕入月コホート別に30/60/90日販売率・在庫年齢を比較 → 欠損と母数を確認 → 運用集計と会計帳簿を照合`

入金、商品粗利益、取引貢献利益、会計上の利益・所得・税額を同一指標として扱わない。

## 必須状態

- 初回・空
- 入力途中・自動保存
- オフライン・送信待ち
- 写真権限なし
- 必須情報不足
- AI確信度が低い
- 承認待ち・差戻し
- 個人版 `手動・本人確認`
- Shops `連携準備中`、`試験環境`、`公式API`
- 外部連携失敗・再試行
- 二重販売・在庫競合
- 証憑不足・入金差額
- CSV出力済み・重複警告
- 権限なし
- 無料枠上限
- 画像加工待ち・処理中・要確認・失敗・再処理・承認済み
- Photoroom Pro手動ZIP・公式API未接続・許諾確認待ち・利用量上限
- 採寸定義未選択・必須欠落・2回差・理由付き保存・再承認待ち
- 原価未配賦・送料未確定・返品期間未満・母数不足・会計未照合
- 在庫番号発行待ち・格納待ち・商品/場所不一致・場所停止・容量超過
- 在庫移動の同期待ち・再読取・競合・ラベル旧版/無効・手入力fallback
- 棚卸中・未発見候補・誤棚・予定外発見・再確認待ち・差異承認待ち
- 返品隔離・検品待ち・再格納待ち・廃棄承認待ち

## モバイルUIの固定条件

- 1画面1目的。片手操作できる位置に主要ボタンを置く。
- 主要操作領域は44×44pt以上。
- 採寸は1項目を大きく表示し、図、前回値、単位、許容範囲、再測定を示す。
- 撮影は前面、背面、タグ、傷などの残数を表示する。
- 通信切断時も入力を失わず、送信待ち件数を見せる。
- 外注者には担当作業だけを表示し、原価、利益、帳簿、購入者住所を既定で隠す。
- AI候補と確定値を色だけでなく、見出し、アイコン、文言で区別する。
- 在庫作業は商品と場所を順に大きく読み取り、現在地の階層、場所写真、読取結果、人の確定を同じ画面で確認できる。
