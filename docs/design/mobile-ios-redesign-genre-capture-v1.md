# スマホ版・ジャンル別の検品／撮影／採寸 v1

- 作成日: 2026-08-25（JST）
- 状態: Slack承認済みのB案＋C機能を高精度モックへ反映する設計基準
- 対象: 完全無料PWAのスマホ作業画面
- 実装境界: 個人メルカリへの自動出品、画面操作代行、非公開API、スクレイピングは行わない

## 確認できた事実

- 利用者提供の公開出品例を、代表的な衣類とバッグに限定してブラウザで手動確認した。
- 衣類は全体写真に続き、前後、ブランド・サイズ表示、品質表示、襟・袖・裾・留め具などの細部を撮る構成だった。
- バッグは前後に続き、底、左右側面、開口部、内側、収納部、持ち手、金具、表示タグなどを撮る構成だった。
- 実アカウント名、URL、商品ID、実画像は本書とモックへ保存しない。
- 現行実装の写真roleと固定pilotは少数の基準写真を前提としている。下記の通常出品向け項目をそのまま固定pilotへ追加する判断はしていない。

## モックへ反映する推論

最初に商品の種類を選び、その種類に必要な `検品する場所`、`撮る写真`、`測る場所` を切り替える。写真枚数を固定せず、最低限の基準写真と、商品固有の細部、気になる箇所を分ける。

## 撮る写真

| 商品の種類 | 基本の写真 | 商品ごとの細部 |
|---|---|---|
| シャツ・ポロ・ブラウス | 正面、背面、ブランド・サイズ表示、品質表示 | 襟元、袖・袖口、裾、ボタン、ロゴ・柄、気になる箇所 |
| ニット・カーディガン | 正面、背面、ブランド・サイズ表示、品質表示 | 首元、袖口、裾、ボタン、編み地・毛玉、気になる箇所 |
| ジャケット・コート・ベスト | 正面、背面、ブランド・サイズ表示、品質表示 | 襟・ラペル、袖口、前開き、裏地、ポケット、裾、気になる箇所 |
| パンツ・スカート | 正面、背面、ブランド・サイズ表示、品質表示 | ウエスト、ファスナー・留め具、裾、脇、ポケット、裏地、気になる箇所 |
| ワンピース | 正面、背面、ブランド・サイズ表示、品質表示 | 首元、袖、ウエスト、裾、背面ファスナー、裏地、気になる箇所 |
| バッグ | 正面、背面、開口部、底、左右側面、内側 | 収納部、持ち手・ストラップ、角、金具、表示タグ、気になる箇所 |

バッグの表示タグや金具は真贋を自動判定するためではなく、状態と表示情報を人が確認するために撮る。

## 気になる箇所の登録

各部位は、人が次のどれかを選ぶ。

- `未確認`
- `問題なしを確認`
- `気になる点あり`

`気になる点あり` では、写真上をタップして番号付きマーカーを置き、次を登録する。

- 場所
- 種類: 汚れ、傷、毛玉、ほつれ、色あせ、剥がれ、その他
- 程度: 小さい、目立つ、使用に影響
- 全体の中で場所が分かる写真
- 必要な場合の接写
- 短いメモ

においなど写真で示せない内容は写真を必須にせず、確認者と説明を残す。アプリやAIが `問題なし` を自動確定しない。

## 測る場所

| 商品の種類 | 基本の採寸 | 条件による追加 |
|---|---|---|
| シャツ・アウター | 肩幅、身幅、着丈、袖丈 | ラグランは肩幅・袖丈の代わりに裄丈 |
| ニット | 肩幅、身幅、着丈、袖丈 | `自然な状態・伸ばしていない` を表示 |
| パンツ | ウエスト平置き幅、股上、股下、わたり幅、裾幅 | 平置き幅と一周を別表示。幅×2は参考値 |
| スカート | ウエスト平置き幅、丈 | ヒップ幅、裾幅、前後丈 |
| ワンピース | 身幅、総丈 | 肩幅、袖丈、ウエスト幅、ヒップ幅 |
| バッグ | 幅、高さ、マチ | 持ち手、ショルダー最短・最長、重さ |

すべての採寸で、測る線、単位、測り方、測定写真、測定者、日時を表示する。大きな差がある場合は自動確定せず `測り直し` へ送る。

## B案の作業カードへ表示する内容

- `検品 2/6`
- `写真 7/10`
- `採寸 3/5`
- `気になる点 2件`
- `未確認 1件`
- `作業を続ける`

完了、注意、未確認は色だけでなく、アイコンと日本語を併用する。

## 実装時にSolが決めること

写真roleを大量に増やす前に、次の関連を設計する。

- 写真チェック項目ID
- 検品部位
- 気になる点ID
- 証拠写真
- 商品種類と版

これにより同じ `気になる箇所の写真` でも、どの部位・どの指摘の根拠かを追えるようにする。既存データ、固定pilot、状態遷移、監査へ影響するため、Luna/Terraだけでデータ構造を確定しない。
