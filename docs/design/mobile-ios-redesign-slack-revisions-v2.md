## 修正する画像

### Board 01 — ログイン

- 現行ログイン画面の見た目を差し替える。
- 最終ロゴは勝手に決めず、記号だけのオリジナルロゴを3案提示する。
- 3案とも、ロゴを上部、`メールアドレス`、`パスワード`、`ログイン`を下部に配置する。
- 実在サービスのロゴ、商標、Appleロゴ、マーケットプレイスのロゴは使わない。
- 3案から利用者が1案を選んだ後にBoard 01全体のv2を確定する。

### Board 02 — 仕入れ

- 卸仕入れを標準として、最初の書類を`請求書`にする。
- `店舗で購入した場合はレシート`という副選択肢を残す。
- 請求書1枚から複数の商品行を読み取り、行ごとに数量・単価・商品名を人が確認する。
- 読み取り結果は候補であり、アプリだけで仕入れ内容や原価を確定しない。

### Board 03 — 格納前の確認

- 中古商品は商品バーコードがない場合が多いため、商品確認は`番号を入力`、`ラベルを読む`、`今回は使わない`から選べるようにする。
- `今回は使わない`は、事前に割り当てた在庫番号と商品写真を人が照合して進む。
- 通常導線には、作業工程設定で使うと決めた工程だけを表示する。

### Board 06 — タグ・写真編集

- 品質タグの文字、ブランド名、サイズ、色、素材はOCR（写真の文字を読み取る機能）の候補として表示し、人が確認する。
- 文字でないブランドマークはOCRだけで確定できないため、`画像からの候補`または`手入力`として分ける。
- 写真編集は、`加工用ZIPを書き出す → 利用者がPhotoroomで編集する → 加工済みZIPを戻す → 原本と比較 → 人が承認`とする。
- CodexやRPAによるPhotoroomブラウザの自動ログイン・クリックは行わない。
- P0はPhotoroomなしでも完了でき、外部API、APIキー、有料サービスを必須にしない。

### Board 07 — 梱包写真

- 1人運用では梱包写真を標準で使わない設定を用意する。
- チーム運用や証拠を残したい場合だけ、梱包写真を工程に表示できる。
- 梱包写真を使わない場合は、商品取り出しの次に発送確認を表示する。

### Board 10 — 商品種類

- `スーツ`と`セットアップ`を追加する。
- スーツは上着とパンツを一組として、上下の全体、上着の細部、パンツの細部、ブランド・サイズ、品質表示、気になる箇所を案内する。
- セットアップは上下または複数点の組み合わせを一組として、構成品一覧と各構成品の不足を確認できるようにする。

## 共通の作業工程設定

設定画面に次を置く。

| 設定 | 選択肢 | 通常導線への影響 |
|---|---|---|
| 運用人数 | `1人` / `チーム` | 梱包写真など証拠工程の初期値を切り替える |
| 仕入れ書類 | `請求書を主に使う` / `レシートを主に使う` / `毎回選ぶ` | 仕入れ開始時の最初の画面を切り替える |
| 商品の読み取り | `使う` / `必要な時だけ` / `使わない` | 商品バーコード・ラベルの画面を表示または省略する |
| 梱包写真 | `使う` / `使わない` | 発送導線に梱包写真を表示または省略する |

- 変更前に、どの工程が表示・非表示になるかを日本語でプレビューする。
- 設定変更は今後の新しい作業へ適用し、進行中の作業は勝手に飛ばさない。
- 重要な人による確認、商品と保管場所の照合、発送内容の確認は非表示にできない。

## 再承認の単位

1. ログインのロゴ案A・B・Cから1案を選ぶ。
2. Board 02、03、06、07、10の修正版を確認する。
3. 共通の作業工程設定を確認する。
4. Photoroomは手動受け渡しでよいかを確認する。ブラウザ自動操作へ変える場合は、製品安全境界の再検討が必要。
