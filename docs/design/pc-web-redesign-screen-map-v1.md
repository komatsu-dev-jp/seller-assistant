# PC版Web・全画面再確認マップ v1

- 作成日: 2026-08-26（JST）
- 状態: モック作成前
- 対象: モバイル版で承認したP0全導線と、PCだけの管理・比較・設定画面
- 承認単位: 13ボード、各4画面、合計52画面相当
- 位置づけ: 完成前の画面見本。実装済みの証拠ではない

## 共通デザイン

- 左ナビ: `ホーム / 作業 / 仕入れ / 商品 / 注文・発送 / 在庫 / 会計 / メンバー / 設定`
- 上部: 画面名、検索、通知、利用者メニュー
- 本文: 白と薄いグレー、青い主操作、緑の確認済み、オレンジの要確認、赤は停止だけ
- PCでは一覧と詳細を同時に見られるようにするが、文字を詰め込みすぎない
- 主見出しには初心者向けの日本語を使う
- 避ける主見出し: `OCR`、`ロケーション`、`mapping`、`profile`、`プレフライト`、`憑依`
- やむを得ない`CSV`などは、`?`で「表計算や会計ソフトへ渡すファイル」と説明する
- 架空データだけを使い、住所、口座、実商品URL、実アカウント名を表示しない

## 安全境界

- 外部販売サイト、Photoroom、Notion、会計サービスを自動で開いて操作しない
- スクレイピング、非公開API、Cookie共有、RPA、自動ログインを使わない
- 個人版の出品、価格変更、セール、返信は本人が公式画面で行う
- 写真原本を上書きせず、GitHub、Slack、Notion、公開URLへ自動保存しない
- AIの文章、価格、会計項目は候補。人が確認する
- 見込みと実績、運用上の粗利と会計上の利益・所得・税額を同一にしない
- 重要な保存、承認、CSV作成、発送記録には確認工程を残す
