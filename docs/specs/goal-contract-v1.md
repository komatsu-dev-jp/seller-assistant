## 1. 完成像

iPhoneのホーム画面へ追加できるPWAで仕入証憑、写真、採寸を商品SKUへ集め、現物1点へ変更不可の在庫管理番号を付け、商品と場所のコードを確認しながら部屋・棚・段・箱へ格納する。PC Webでは場所写真と現在地、画像確認、文章候補、公式出品経路への引渡し、受注、配送、棚卸差異、収益、会計候補までを同じ履歴で追える業務アプリを作る。

外注担当には仕事に必要な情報だけを期間限定で見せ、承認と監査履歴を残す。AIは候補を作るが、商品、価格、公開、税務を自動確定しない。

## 2. MVPで完成させるもの

MVP（最初に実用性を検証できる最小版）では、次の縦導線を一つのシステムとして動かす。

1. 組織、利用者、役割、外注担当、最小権限、監査ログ。
2. SKU作成、仕入先、原価配賦候補、レシート/証憑の原本保存とOCR確認。
3. ProductSKUと現物InventoryUnitを分け、在庫管理番号、場所階層、部屋全景/正確位置の写真、内部商品/場所ラベルを管理する。
4. iPhone PWAのカメラ撮影、写真チェックリスト、手入力を基本とするタグ情報、人が入力するカテゴリ別採寸、最小情報だけのオフライン同期待ち保存。
5. 商品→場所→人の確認による格納・移動・ピッキング、棚卸差異、再確認、返品隔離。
6. バーコード/タグ/型番の候補、利用者が公式画面で確認して戻す商品・価格根拠。
7. 加工用ZIP、加工済みZIP再取込、SKU照合、原本比較、承認。Photoroom Proは既存契約と利用権が確認できた場合だけ本人操作の選択肢にし、P0は有料サービスなしでも完了できる。
8. 根拠付きAI商品説明候補、未確認表示、担当者確認、出品準備パッケージ。
9. 個人向け販売画面への本人コピー/公式画面引渡し、および条件を満たす場合のShops公式CSV。反映は人が確認する。
10. 注文、現物引当、二重読取、梱包、期限付き配送先表示、発送、返品、在庫復帰。
11. 売上、返金、商品原価、手数料、送料、取引貢献利益、仕入先別分析、欠損表示。
12. 証憑と事実から仕訳候補を作り、人または税理士が確定する会計CSV。
13. 住所、原価、利益、税務資料、場所情報を除外したNotion一方向ミラー。
14. Free、Solo Pro、Teamをサーバー側権限で分ける仕組み。金額と上限は実測後に決める。

標準ホームは承認済み案C「オーナーパルス」、日々の高密度処理は案B「高速ワークベンチ」、外注引継ぎは案C「チーム・リレー」を使う。

実装順はP0（試験SKU1点を仕入証憑→在庫番号→場所写真付き格納→撮影/採寸→本人出品引渡し→注文→二重読取→発送→棚卸差異→会計CSVまで通す縦導線）→P1（複数SKU、画像バッチ、Shops CSV、価格・分析、Notion、プラン/高度チーム、箱の中身一括移動、複数拠点、最短ピッキング順）とする。P0のE2E、権限、財務、原本、在庫不変条件、監査テストが全合格するまでP1を開始しない。

## 3. MVPの対象外

- 個人向け販売アカウントの自動出品、自動値下げ、自動巡回、資格情報保管。
- 非公開API、画面の無人操作、スクレイピング、CAPTCHA回避。
- 自作の写真一括加工エンジン、契約前のPhotoroom API組込み。
- AIによる採寸、商品同定、真贋、価格、公開、仕訳、税区分、申告の自動確定。
- 税務申告の代理作成・提出、個別税務助言の断定。
- Notionを確定データの正本にすること。
- 複数市場の非公式連携、本番公開、App Store申請、PRのマージ。
- 機器・契約・現場運用を確認する前の専用ラベルプリンター、RFID、GLN/SSCC/GRAI等のGS1識別キー発行。

自作の写真一括加工は、MVP後に同じ `ProcessingJob` / `ProcessingRecipe` / provider契約へ追加できる形までをMVPで用意する。

## 4. 技術の基準

- PWA/PC Web: Next.js + React + TypeScript。iPhoneはSafariの「ホーム画面に追加」でアプリ表示し、Web標準のカメラ入力と手入力fallbackを使う。
- API: PWAとPC画面で共通の業務ルールを持つ独立Node.js/TypeScript API。
- データ: PostgreSQLを正本、非公開オブジェクトストレージへ原本を保存。
- 契約: OpenAPI/JSON Schema、冪等性キー、outbox、監査イベント。
- 認証/権限: 組織分離、RLS（データベース側でも他組織の行を見せない仕組み）、期限付き署名URL。
- AI: サーバー経由、構造化出力、根拠・モデル・プロンプト版・人の判断を分離保存。

依存サービスの正確な版、料金、保存地域、API契約はGoal開始時に公式情報を確認し、有料契約や超過課金を勝手に有効化しない。
