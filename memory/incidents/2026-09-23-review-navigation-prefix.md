# 公開モバイル作業ボタンの404

- status: candidate
- 本人報告: 疑似端末表示は解消したが、保管などの作業ボタンで404となる。
- 再現: 公開作業一覧の保管ボタンをクリックすると`/seller-assistant/seller-assistant/mobile/screens/14/`へ移動して404。
- 原因: 静的書き出し後処理がJavaScript内のURL文字列へ公開先prefixを付け、その後実行時の連結で同じprefixをもう一度付けていた。見本写真のURLも同様。
- 修正: 公開先prefixが既にある場合は再付加しない共通関数を、作業移動と見本写真へ適用。保存処理・承認デザインは変更しない。
- 検証: 処理前・処理後・prefixなしのURL、類似ディレクトリ名、関数利用の契約を38テストで確認。独立レビューP1=0/P2=0。公開用書き出しのブラウザで保管14・検品17・撮影20・採寸25への遷移を確認。
- 予防: HTML直アクセスだけで合格にせず、公開用処理後の成果物で実ボタンを押し、遷移先URLまで確認する。本人実Safariでの結果は公開後に確認する。
